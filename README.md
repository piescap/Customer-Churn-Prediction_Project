# Customer Churn Prediction Project

<p align="center">24 June 2025</p>

## Overview
The **lab exam project** for the course: *"Artificial Intelligence for Communication and Marketing"* held by **Professor Sergio Suriano** in the **[L-31] Artificial Intelligence** bachelor's degree program.

The main objective of the project is to build a **machine learning model capable of predicting customer churn**, i.e., whether a customer is likely to stop using an e-commerce platform, based on transactional and behavioral features.

---

## Objectives
- Analyze a real-world e-commerce dataset related to customer behavior  
- Perform data preprocessing, cleaning, and outlier treatment  
- Handle class imbalance using oversampling techniques  
- Train and evaluate multiple machine learning models  
- Predict whether a customer will **churn (leave)** or **not churn (stay)**  

---

## Dataset
The dataset (`data.xlsx`) contains **5,630 records** with **20 attributes** describing customer transactional behavior.
